Run a vulnerability analysis

Choose an area and a period. The service runs the model in Google Earth Engine on your current AHP weights (see the AHP tab) and returns statistics and GeoTIFF rasters. Typical runs take a few minutes; the same settings run again are served from cache.

Presets:

Periods must be 30 days to about 3 years, from 2016 to about 6 weeks ago (satellite rainfall and vegetation data lag). Population is WorldPop 2020 for every period.

Pairwise comparison matrix (Saaty 1–9)

Row criterion vs. column criterion: 9 = row far more important; 1/9 = column far more important. Only the upper triangle is editable; the lower triangle is reciprocal by construction. Re-elicit these judgements for Akwa Ibom with local entomology/vector-control experts.

Ecological concordance with reported incidence

Rates, not counts. Counts mostly track population size; the Bayelsa paper flagged this as a limitation. With ~31 LGAs treat every result as hypothesis-generating (ecological inference, MAUP, DHIS2 reporting completeness).

Weight sensitivity (Monte Carlo)

Each AHP weight is multiplied by a log-normal factor, weights are renormalised, and LGAs are re-ranked 1,000 times. Bars show the 5th–95th percentile rank; the dot is the baseline rank (1 = most vulnerable).

Workflow

      
    
        
  1. Set the weights on the AHP weights tab (start from the Bayelsa matrix, then re-elicit for Akwa Ibom).
    2. 
        
  2. Copy the script from the Earth Engine tab. Add your OSM roads and GRID3 facilities assets (or leave them null and their weight is redistributed).
    3. 
        
  3. Run the two exports, download the CSV and GeoJSON from Drive.
    4. 
        
  4. Load both files here. Enter DHIS2 2024 confirmed cases per LGA in the table.
    5. 
        
  5. Change weights freely: LGA mean MVI, ranks, sensitivity and quadrants update instantly because a weighted linear combination of layer means equals the mean of the combination. Pixel classes and class populations only change when you re-run the script.

What differs from the Bayelsa paper

      
    
        
  • Score direction flipped: 1 = most vulnerable, so higher MVI means higher suitability/exposure.
    • 
        
  • Classes use equal intervals on the 2nd–98th percentile range, so outlier pixels don't stretch the bins.
    • 
        
  • Validation uses incidence per 1,000, Spearman as well as Pearson, Benjamini–Hochberg adjustment, and a weight-perturbation sensitivity analysis (the paper lists these as future work).
    • 
        
  • Health-system access is shown as a second axis instead of being folded into one index.
    • 
        
  • UTM zone 32N (EPSG:32632) fits Akwa Ibom (about 7–8.2°E).
    • 
        
  • Open datasets: Dynamic World LULC, MERIT Hydro (streams and TWI), CHIRPS, MODIS, WorldPop 2020, FAO GAUL LGAs.
    • 
        
  • The pairwise matrix is rebuilt from the published upper triangle with exact reciprocals; the published lower triangle is not perfectly reciprocal, so weights can differ slightly from Table 3.
